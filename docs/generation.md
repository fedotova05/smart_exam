# Генераторы

Generator::generateTask принимает id, семейство, seed, максимальное число попыток
и уже выданные выражения. Семейства: дроби, линейное и квадратное уравнение,
прямая, парабола. Графические семейства содержат две связанные части: нули и график
одной функции. Коэффициенты выбираются один раз на всё задание.

Используется стандартный mt19937 с явным seed и ограничением по остатку, поэтому
результат не зависит от реализации uniform_int_distribution. При повторе seed
увеличивается; сохраняется фактически использованный seed. По умолчанию 32 попытки,
после исчерпания возвращается ошибка, а не бесконечный цикл.

generateAndSave сохраняет конкретные выражения, параметры, seed и версию math-1
как черновик. Публикация — отдельное действие Store::publish после проверки.
Для генерации заранее метод вызывается несколько раз, для генерации по запросу —
при запросе нового материала. В обоих случаях старые попытки читают сохранённую версию.
Перед сохранением должны существовать навыки fractions, linear, quadratic,
line_graph, parabola_graph для соответствующих семейств.

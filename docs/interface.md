# Интерфейс — KChernmo

Окно 1200×800, минимум 1024×720. В большом окне интерфейс центрируется без растягивания текстур.
В уменьшенном окне сохраняются пропорции и доступ ко всем кнопкам.
Tab переводит фокус, Shift+Tab возвращает его, Enter нажимает кнопку.
В полях работают курсор, Backspace, Delete, Ctrl+A/C/V. Длинные списки прокручиваются колесом.

1. При запуске выбрать «Я ученик» или «Я учитель». Это локальное разделение экранов без пароля.
2. Ученик выбирает личный профиль или создаёт новый. «Демонстрация» открывается отдельно.
3. На главной ученика — продолжение или выбор тем. Два режима: «Тренировка» и «Проверка знаний». Можно выбрать несколько тем и уточнить навыки. В тренировке после ошибки доступны повторная попытка и разбор на простых заданиях.
4. Учитель работает с заданиями, навыками и пакетами. В кабинете выбирает ученика для истории или подготовки занятия. Подготовленное занятие ученик продолжает в своём профиле.
5. На экране решения слева показан маршрут. Введите ответ, нажмите «Проверить», затем «Завершить задание». Итоговый ответ и промежуточный шаг отправляются отдельно.
6. В тренировке кнопка следующего задания завершает выполненный маршрут. В проверке знаний занятие закрывается после последнего задания. Досрочное завершение требует подтверждения; невыполненные задания остаются в плане.

В истории отдельно показаны баллы и число завершённых заданий. Задание может состоять из нескольких
частей с разными баллами. Первый самостоятельный верный ответ даёт примерно 58% по соответствующему навыку.
Процент навыка — прогноз по самостоятельным решениям, не доля правильных ответов.
Подсказка исключает обновление соответствующего навыка; исправленная ошибка всё равно учитывается.
Каждый навык получает не более одного наблюдения за задание. При отложенной проверке баллы
и обновлённые навыки скрыты до разрешённого момента. Для адаптивного занятия максимум баллов
указан только за выданные задания, поскольку следующие ещё не выбраны.

Формулы: `x`, `^`, `/`, `sqrt(...)`. Корни разделяются `;`, нет корней — `none`,
все действительные числа — `all`. Панель вставляет символы в позицию курсора.
Предпросмотр использует дерево общего парсера; собственного вычислителя в UI нет.
«Шаги (необязательно)» доступны только для линейных уравнений. Новое уравнение и действие
вводятся справа; итоговый ответ — слева. Можно сразу отправить итоговый ответ.
Квадратные уравнения решаются на бумаге: программа проверяет корни, а не запись дискриминанта.
Это правило действует и для старых занятий с сохранённым флагом `guided`.

«Посмотреть демонстрацию» открывает историю разбора квадратного уравнения.
«Пройти похожий маршрут» создаёт отдельный пробный профиль; ответы и маршрут в нём настоящие.
Прежний профиль «Демонстрация» с двумя примерами также сохранён.
Данные создаются один раз через обычные службы проверки. Существующие профили и задания не перезаписываются.
Состав мининабора: [demo.md](demo.md).

Прямая: поставить две точки и перетаскивать их. Парабола: ввести `a`, `b`, `c`
для `y=ax²+bx+c`, нажать «Задать a, b, c». Колесо меняет масштаб,
правая кнопка сдвигает поле. Привязка и относительный допуск задаются в редакторе.
Масштаб окна не влияет на проверку. Интервалы пока представлены только структурой данных.

«Банк заданий»: поиск, черновик, части, общее условие и функция, навыки и баллы.
Опубликованное задание открывается как новая версия. Рисунки указываются относительно `data/`.
Публикация требует корректной структуры и доступных файлов. Для навыков используются коды из карты знаний.

«Мой прогресс»: таблица навыков по теме, оценки, наблюдения и подсказки. Неизученные навыки — «Нет данных».
Сверху показано среднее по навыкам с наблюдениями и их число. Это не процент освоения всей темы.
Счётчик помощи относится к связанным заданиям целиком. «Карта связей» открывает граф;
учитель может перемещать узлы и редактировать связи. Кнопка «Как считается оценка?» объясняет показатели.
Большое поле прокручивается колесом. Рейтинг продолжает использоваться при подборе заданий.

Классы: `App` управляет окном; `Screen` — фокусом и элементами;
`Widget` наследует `Drawable` и `Transformable`; `FormulaView`, `GraphView`, `SkillMap` рисуют данные.
`WelcomeScreen` отвечает за выбор роли и профиля, `AppContext` хранит текущую роль.
`LessonSetupScreen` собирает занятие учителя, `TrainingSetupScreen` задаёт темы и режим ученика.
`TrainingDemoScreen` показывает пример, `ProgressScreen` — сводку навыков.
Созданные генератором примеры сохраняются в банке только при запуске занятия.
`SchoolService` связывает экраны с хранилищем и занятиями, `LessonProgress` содержит сводку занятия.
В кнопках нет SQL и математических правил проверки.
Неотправленные ответы сохраняются между частями в открытом приложении;
после перезапуска восстанавливаются отправленные ответы из SQLite.

Подробности подбора, границы диагностики и хранение: [training.md](training.md).

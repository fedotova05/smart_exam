# Работа с приложением

## Вход

Ученик выбирает или создаёт профиль. Учитель входит по локальному паролю;
при первом входе задаёт его сам. «Сменить роль» завершает вход учителя.
Профили можно убрать в архив и восстановить без потери истории.

## Ученик

1. Выбрать темы или отдельные навыки и число заданий.
2. Выбрать режим: тренировка с немедленной проверкой или проверка знаний с фиксированным набором.
3. Ввести ответ, отправить его, затем завершить задание.
4. После ошибки в тренировке выбрать повторную попытку или разбор на простых заданиях.
5. Посмотреть историю, баллы и прогресс по навыкам.

Формулы вводятся через `x`, `^`, `/`, `sqrt(...)`. Корни разделяются `;`,
нет корней — `none`, все действительные числа — `all`.
Шаги доступны для линейных уравнений; обязательность задаётся в редакторе задания.
Для квадратного уравнения проверяется итоговый набор корней.

Прямая строится по двум точкам. Парабола задаётся коэффициентами `a`, `b`, `c`.
Колесо меняет масштаб, правая кнопка сдвигает поле. Черновики текста и графика сохраняются.

Пауза доступна, если разрешена условиями занятия. В режиме непрерывного времени
выход не останавливает таймер. Режим без продолжения запрещает возврат после закрытия программы.

Баллы относятся к заданию, процент навыка — к оценке освоения по истории решений.
Нет данных — не ноль процентов. Подсказка исключает самостоятельное наблюдение;
исправленная ошибка остаётся учтённой. При отложенной проверке оценки скрыты до завершения.

## Учитель

- **Банк:** создать черновик, проверить и опубликовать. Публикация не изменяется;
  для исправления создаётся новая версия.
- **Занятие:** выбрать задания из банка, создать примеры генератором или включить подбор.
  Указать навыки, число заданий, время, подсказки и момент показа результата.
- **Шаблон:** сохранить фиксированный вариант или условия адаптивного подбора.
  Назначенное занятие не меняется при редактировании шаблона.
- **Ручная проверка:** выбрать часть, изучить исходное условие и ответы,
  записать вердикт и причину. Автопроверка сохраняется отдельно.
- **CSV:** выгрузить текущий список результатов; доступны фильтры по ученику и непроверенным частям.
- **Пакеты:** импортировать JSON с сопоставлением навыков. Импорт создаёт черновики.

Окно: 1200×800, минимум 1024×720. Tab/Shift+Tab меняют фокус, Enter нажимает кнопку.
В полях работают курсор, Backspace, Delete, Ctrl+A/C/V; пароль нельзя скопировать.
Длинные списки прокручиваются колесом.

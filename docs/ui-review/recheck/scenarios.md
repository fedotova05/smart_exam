# Проверка сценариев и визуальных изменений

До изменений проверены переходы вход → назначение → решение → возврат, создание занятия из банка и генератора, самостоятельная практика, история и прогресс.

| Сценарий | Проблема | Изменение |
| --- | --- | --- |
| Несколько назначений | Раньше открывалось только последнее | Список независимых занятий, продолжение выбранного |
| Вернуться к незавершённому набору | Досрочный выход мог закрыть оставшиеся задания | «Продолжить позже» сохраняет весь набор |
| Открыть завершённое занятие | Показывалась общая история | История выбранного занятия с переходом ко всем решениям |
| Оценить свой прогресс | Таблица процентов не объясняет следующий шаг | Сводка, последние результаты, группы навыков и повторение |
| Найти подробности | Показатели и методика одновременно на экране | Сводка → навыки → объяснение |
| Взаимодействие | Резкая смена цвета кнопок | Короткая реакция наведения; появление столбцов графика |

Визуальные ориентиры: [уровни навыков Khan Academy](https://support.khanacademy.org/hc/en-us/articles/115002552631-What-are-Course-and-Unit-Mastery), [короткие анимации для настольных приложений Material Design](https://m1.material.io/motion/duration-easing.html). Использованы принципы подачи, без копирования оформления.

График баллов показывает результаты отдельных заданий, а не изменение освоения навыка: сложность заданий различается. Отложенная проверка и предварительные баллы не должны раскрываться через диаграммы. Порядок завершения берётся из журнала learning_events; для данных до миграции 008 он восстановлен по порядку попыток.

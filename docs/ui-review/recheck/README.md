# Повторная проверка

Это снимки приложения SFML, не макеты. Основные экраны сняты Release-командой --capture с базой в памяти. lesson-options, review-queue, review-detail, history-selected-lesson и graph-answer сняты проверками интерфейса Release без общего меню. Личная база для проверки не открывалась.

## Основные изменения

- [Назначения](assignments.png): два отдельных занятия, одно из трёх заданий. Новая практика не заменяет их.
- [Моя практика](practice-list.png): самостоятельные тренировки и проверки отдельно от назначений.
- [Редактор](task-editor.png): вопрос, выражение и только параметры выбранного типа. Части и дополнительные поля вынесены отдельно.
- [Варианты ответа](editor-kind-5.png), [числовой ответ](editor-kind-4.png), [выбор типа](editor-type-picker.png).
- [Условия занятия](lesson-options.png): сохранение шаблона вынесено в отдельную форму.
- [Сводка прогресса](progress-overview.png): последние результаты, понятные группы навыков и следующий шаг. Столбец открывает ответ; рекомендация подставляет навык в тренировку.
- [Подробности по навыкам](progress-details.png), [пустой профиль](progress-empty.png), [отложенная проверка](hidden-progress-table.png).
- [История выбранного занятия](history-selected-lesson.png) с переходом ко всем решениям.
- [Карта навыков](knowledge.png): одна тема, внешние связи по запросу, скруглённые карточки, плавные стрелки и выделение связей выбранного навыка. [Карта на широком экране](knowledge-1920.png). Есть переход к тренировке выбранного навыка.
- [Полный экран](home-fullscreen.png), [возврат в окно](home-window-restored.png), [2560×1440](progress-2560.png).

## Причины размытия и исправления

До изменения процесс не объявлял DPI awareness, а панели рисовались в логическом разрешении и сглаживались как растровые текстуры. Windows мог дополнительно масштабировать окно. Теперь DPI задаётся до создания графического контекста, шрифты получают размер в физических пикселях, а промежуточные поверхности пересоздаются при изменении масштаба. Устранено повторное дробное растягивание глифов: размер шрифта соответствует физическим пикселям, текст и панели выровнены по пиксельной сетке. Область отрисовки занимает всё окно. На широких экранах расширяются карточки, поля, списки и графики; подписи переносятся под новую ширину. Буквы сохраняют пропорции. Интерфейс запускается на весь экран; F11 и кнопка сверху возвращают оконный режим.

Проверены физические размеры поверхностей и шрифтов при масштабах 0.9, 1, 1.25, 1.35, 1.5 и 2; снимки окна 1024×720, 1200×800, 1600×900, 1920×1080, 2560×1440 и 3440×1440; реальное пересоздание окна в полный экран и обратно. При другом соотношении сторон ширина разметки адаптируется без боковых полей. Отдельный монитор с другой настройкой DPI и системная доступность для скринридера не проверялись.

## Сохранение занятий

Миграция 012 добавляет источник и название занятия. Старые записи сохраняются с пометкой «ранее сохранено». Источник старых записей не угадывается. Новые назначения, практика и несколько незавершённых попыток в разных занятиях хранятся независимо. Выход из назначения через «Продолжить позже» сохраняет оставшиеся задания. Ограничения времени продолжают действовать согласно условиям занятия.

Закрытые старые занятия остаются в разделе завершённых. Изменение не переоткрывает их автоматически.

## Проверки

Debug (smart_exam_review.exe) и Release: 17 групп предметных проверок, сценарии интерфейса и демонстрация прошли. Отдельное имя Debug позволяет собрать приложение рядом с уже открытой старой программой.

Дополнительно проверены: два назначения и личная практика; три последовательных задания в одном назначении; сохранение выбранного занятия; черновики при переключении и после перезапуска; сохранение старого занятия при миграции; отложенные оценки при переключении занятий; все семь типов редактора и возврат к прежнему типу.

Запуск из корня через run.bat выбирает Release, если он собран; иначе Debug.

## Сценарии, скорость и анимации

[Найденные проблемы и решения](scenarios.md). Реализованы реакции кнопок на наведение (120 мс) и появление столбцов (200 мс). Действия доступны сразу, текст неподвижен. Системное отключение анимаций Windows учитывается при запуске через [SystemParametersInfo](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-systemparametersinfoa). В снимках анимации выключены для воспроизводимости.

На тестовом профиле с историей решений сводка построилась за 3–20 мс в нескольких прогонах в Release на текущем компьютере. Это локальное измерение подготовки экрана, не обещание времени запуска приложения или работы на любой базе. Дополнительно проверены переход из диаграммы к нужному ответу, рекомендация в тренировку, Enter в списке занятий, чужой владелец занятия, пустой профиль и запрет раскрытия отложенных оценок.

Дополнительно проверены растянутые поля и кнопки, попадание мышью в диалог и карточку карты после изменения ширины, сохранение введённого текста при возврате к прежнему размеру. Команда снимков проверяет, что область отрисовки занимает все пиксели окна.

# Повторная проверка экранов

Обзор выполнен до общего набора исправлений. Проверены все экраны и вложенные формы в src/ui/screens, существующие снимки Release и общие компоненты отрисовки.

| Раздел | Найдено | Исправление |
| --- | --- | --- |
| Вход и роли | Существенной перегрузки нет | Сохранить две роли и выбор профиля |
| Главная ученика | Одно «последнее занятие» смешивает назначения и личную практику | Отдельный список назначений и отдельная самостоятельная тренировка |
| Кабинет учителя | Неясно, где ученик увидит назначение | Указать раздел и количество открытых назначений |
| Темы и режим | Повторяющиеся пояснения | Короткие подписи, один основной запуск |
| Создание: банк, генератор, автоподбор, корзина | Терминология выбора и избыток инструкций | Оставить параметры текущего способа и краткие подписи |
| Проверка занятия | Пояснения о шагах независимо от типов; нет имени назначения | Название занятия и краткая сводка |
| Условия занятия и шаблоны | Две самостоятельные формы на одном экране | Сохранение шаблона вынести в отдельную форму |
| Решение: число, выражение, уравнение, варианты, график, составное | Основной режим уже сосредоточен на ответе; справка и шаги отделены | Проверить все типы после изменения масштаба |
| Подсказки, шаги, разбор ошибки, маршрут, рисунки | Существенной перегрузки нет | Сохранить отдельные действия и возврат |
| Результат задания и история | Повтор имени, длинные пояснения, узкая история ответов | Укоротить пояснения, увеличить место для ответов |
| Прогресс | Длинная методика под таблицей | Вынести подробности в отдельное объяснение |
| Карта навыков | Все темы и рекурсивные предпосылки создают плотную сеть | По умолчанию одна тема; остальные связи по запросу |
| Редактор навыка и темы | Форма соответствует задаче | Проверить пустые списки |
| Банк | Список и основные действия понятны | Сохранить поиск и статусы |
| Редактор задания | Общие поля для несовместимых типов | Меняющаяся форма, отдельные части и дополнительные параметры |
| Настройка ответа | Формула дублируется; шаги доступны для нелинейных уравнений | Только настройки выбранного типа |
| Предпросмотр | Не все типы различимы | Показывать варианты и тип проверки |
| Проверка учителем | Служебные идентификаторы частей; действие при пустом списке | Читаемые названия, недоступное пустое действие |
| Ученики и архив | Пустой архив постоянно занимает половину экрана | Архив отдельным переключателем |
| Импорт, сопоставление, экспорт, отчёт | Длинные вводные; сами последовательные действия понятны | Сократить вводные |
| Учебный пример | Идентификаторы частей и повторная инструкция | Оставить ответы и короткую инструкцию |
| Меню и диалоги | «Моё занятие» и «Темы и режим» не объясняют назначение | «Мои занятия» и «Тренировка» |
| Полноэкранный режим | Нет DPI awareness; масштаб ограничен 1; панели низкого разрешения | DPI до создания окна, F11, растеризация под физический масштаб |

Дополнительно: SchoolService::start закрывал другие открытые занятия. Нужно хранить источник занятия, не закрывать назначения при запуске практики и выбирать конкретное занятие для продолжения.

Исправления и результаты проверки: [recheck/README.md](recheck/README.md). Назначения поддерживают несколько занятий и несколько заданий в каждом. Досрочный выход из назначения сохраняет незавершённый план.

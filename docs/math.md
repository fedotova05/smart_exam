# Математический ввод

Дроби вычисляются точно: Rational хранит сокращённый числитель и положительный
знаменатель. Их модули ограничены 10^9. При таких границах промежуточные
произведения и суммы помещаются в int64; сокращение выполняется до умножения,
а результат снова проверяется. Переполнение не превращается в неверный ответ.

Поддерживаются числа, десятичная точка или запятая, x, скобки, +, -, *, /, ^,
sqrt(...). Неявное умножение допускается перед x, скобкой и sqrt: `2x`, `2(x+1)`.
Пробел не заменяет оператор между числами. Унарный минус имеет меньший приоритет,
чем степень: `-x^2` означает `-(x^2)`. Степень связывается справа.

Пределы: 512 байтов ввода, 256 токенов, 64 уровня вложенности, 6 десятичных знаков.
Числовая степень — целая от 0 до 8. Ошибка разбора содержит позицию в строке
(с нуля, байты UTF-8). Математический синтаксис ASCII; сообщения — русский UTF-8.
AST хранит вид операции, дочерние узлы и позицию; участник 2 может строить по нему
формулу без собственного разбора текста. Дерево не содержит типов SFML.

Уравнения приводятся к многочлену степени не выше двух с рациональными
коэффициентами. Деление на выражение с x не поддерживается, даже если его можно
сократить: область определения пока не отслеживается. Промежуточные многочлены
также должны иметь степень не выше двух.

Радикалы имеют вид a+b*sqrt(d), d — неотрицательное целое до 1000000.
Квадратные множители выносятся из корня. Для sqrt(n/m) используется sqrt(n*m)/m;
ограничение применяется к n*m. Суммы разных радикалов и деление на радикал
возвращают Unsupported. Сравнение выполняется точно, без допуска double.

Корни в ответе разделяются `;`, например `-sqrt(2);sqrt(2)`; запятая остаётся
десятичным разделителем. Допускаются фигурные скобки и префикс `x=` у числа.
Для отсутствия корней: `none`, `{}` или `нет корней`; для тождества: `all`, `R`, `все`.
Порядок корней не важен. Пустая строка — Incomplete, а не пустое множество.

В свободном режиме шаг проверяется по множеству действительных решений.
В направляемом дополнительно проверяются обе стороны после заявленного действия:
add/subtract (многочлен), multiply/divide (ненулевая рациональная константа),
swap, simplify. Верный промежуточный шаг ещё не заменяет окончательный ответ.

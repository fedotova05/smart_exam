# Задания ОГЭ

Поддерживается первая часть ОГЭ по математике: номера 1–19, программа 2026 года.
Основа состава — [спецификация и кодификатор ФИПИ](https://doc.fipi.ru/oge/demoversii-specifikacii-kodifikatory/2026/ma_9_2026.zip).
Материалы 2027 года не подменяют выбранную программу.

## Загрузка

Ученик открывает «Задания ОГЭ», выбирает номер, подтип и количество, затем
нажимает «Подобрать задания». Можно начать тренировку с полученной подборкой.
Учитель выбирает ещё и ученика, затем назначает ему занятие.

Источник карточек — [«Решу ОГЭ»](https://math-oge.sdamgia.ru/).
Сначала проверяется локальный банк, недостающие карточки загружаются по HTTPS.
Условие, общее описание, ключ и рисунки сохраняются вместе; решения из источника
ученику не показываются. SVG преобразуются в PNG. В условии рисунки помечены
номерами, соответствующими списку изображений.

Завершённые учеником карточки исключаются из новой подборки. Повторный импорт
не создаёт копию той же версии. Изменение условия, ответа или рисунка создаёт
новую версию; старая остаётся в истории. Повреждённые рисунки исключают карточку
из офлайн-подбора, повторная загрузка восстанавливает их.

Карточка содержит источник, внешний номер, год, подтип и ссылку на оригинал.
Подтип определяет навык. В практических номерах 1–5 дополнительно проверяются
слова вопроса о стоимости, процентах, площади и обозначениях; иначе остаётся
общий навык практических задач. Это правило классификации, а не анализ решения.
Для смешанных разделов источника уточняются также задачи на вероятность
и площадь треугольника: они не должны получать навык только по названию раздела.

## Навыки

В `data/oge/curriculum.json` находятся 53 навыка, связи необходимых знаний,
212 коротких упражнений и 53 лекции. Упражнения составлены для проекта.
Они используются при разборе ошибки и доступны без сети.

| Номера | Основные темы |
|---|---|
| 1–5 | Планы, таблицы, единицы, проценты, стоимость, округление, площадь, движение, объём |
| 6–8 | Целые числа, дроби, сравнение, координатная прямая, степени, корни, выражения |
| 9 | Линейные и квадратные уравнения; отдельно доступны дробно-рациональные и системы |
| 10 | Вероятность, деревья событий, частоты и статистика |
| 11–12 | Функции, чтение графиков и расчёты по формулам |
| 13–14 | Неравенства и их системы, арифметическая и геометрическая прогрессии |
| 15–16 | Треугольники, подобие, Пифагор, тригонометрия, окружности |
| 17–19 | Четырёхугольники, средние линии, длины и площади на сетке, утверждения |

Состав навыков покрывает темы первой части. Четыре базовых упражнения на навык
не заменяют весь экзаменационный банк. Подтипы источника объединяют несколько
частных приёмов: отдельная автоматическая классификация каждого приёма пока не выполняется.

## Собственная подборка

Учитель может нажать «Импорт подборки JSON». Формат `oge-2026/1` содержит
от 1 до 100 текстовых задач с проверенными краткими ответами:

```json
{
  "schema": "oge-2026/1",
  "title": "Линейные уравнения",
  "tasks": [
    {"id": "10001", "category": 7, "condition": "Решите 3x + 2 = 14.", "answer": "4"}
  ]
}
```

`id` — строка цифр; `category` — код подтипа из `ogeCategories()`
в `src/application/exams/ExamCatalog.cpp`, а не номер задания на экзамене.
Например, 7 — линейные уравнения номера 9, 43 — квадратные, 6 — дроби номера 6.
Навык назначается автоматически. Полный пример — `data/samples/oge-2026.json`:
19 собственных упражнений для проверки импорта. Ключи хранятся строками,
ведущие нули и порядок цифр сохраняются; точка и запятая в десятичном ответе равнозначны.
Рисунки этим форматом не переносятся; для них используется общий раздел «Пакеты».

## Доступность источников

Проверка 12.11.2026: страницы ФИПИ и архив документов доступны, но соединение
с `oge.fipi.ru/bank/` не устанавливается. Причина ограничения по стране не подтверждена.
Прямой импорт из банка ФИПИ не реализован. Рабочий сетевой источник — «Решу ОГЭ»;
его задания не обозначаются как скачанные из ФИПИ. При недоступности источника
работают сохранённые карточки и локальные подборки.

Загрузка ограничена 20 заданиями и четырьмя страницами за запрос, в интерфейсе —
90 секундами. Карточки без однозначного числового ключа или с неподдерживаемым
ресурсом пропускаются с сообщением. При изменении разметки сайта адаптер нужно обновить.
ЕГЭ и вторая часть ОГЭ в этот импорт не входят.

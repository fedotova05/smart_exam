# Что я реализовала

Я отвечала за внутреннюю логику SmartExam: математику, данные, занятия и подбор.

- Дроби храню как числитель и знаменатель, чтобы не терять точность.
- Выражение разбираю в дерево и привожу к многочлену степени не выше двух.
- Шаги сравниваю по множеству корней; в направляемом режиме проверяю действие.
- Опубликованное задание не изменяю: новая редакция получает новый id.
- Ответы и исправления сохраняю в SQLite. Повторный запрос не создаёт дубль.
- BKT оценивает знание навыка, Elo сопоставляет ученика со сложностью задания.
- Подсказки и непроверенные ответы не использую для обновления модели.

Для показа запускаю `run.bat demo`, затем `run.bat tests`.
Интерфейс делает участник 2. Пока проверена Win32-сборка; x64 проверяется отдельно.

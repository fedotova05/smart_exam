# Кабинет учителя

При первом входе задаётся локальный пароль. Для следующих входов нужен этот пароль.
Выход через «Сменить роль» отменяет права учителя, в том числе для ещё работающего импорта.
Редактирование заданий, тем, навыков и оценок проверяет право доступа в сервисе.

Пароль хранится как PBKDF2-HMAC-SHA256: 600 000 итераций, случайная соль 16 байт,
результат 32 байта. Вычисление и случайные числа предоставляет Windows CNG.
Пароль не шифрует SQLite и не защищает файл от владельца компьютера.

Если пароль забыт: закрыть приложение, выполнить `python tools/reset_teacher.py`
и ввести `СБРОС`. Скрипт сначала сохраняет резервную копию базы в `bin/backups`.
При следующем входе задаётся новый пароль. Учебные данные сохраняются.

В «Управлении профилями» можно создать профиль, убрать его в архив и восстановить.
Архив скрывает профиль из списка входа, но сохраняет историю. Незавершённое занятие
нужно закончить перед архивированием.

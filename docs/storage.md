# Хранение

База создаётся из `db/migrations/001_initial.sql`. SQLite 3.46.1 включена исходниками
из официального архива; SHA3-256 загруженного архива записан рядом с исходниками.
Версия закреплена для совместимости с заголовками TDM GCC 5.1.0; установка сервера не требуется.
Рабочие базы исключены из Git. Схема хранит профили, темы, навыки, версии заданий,
занятия, редакции ответов, помощь, наблюдения и значения моделей до ответа.

Store::saveDraft сохраняет черновик транзакционно. Store::publish проверяет полноту
частей и делает версию неизменяемой. Для изменения опубликованного задания надо
создать новый id. Архивация скрывает задание из подбора, сохраняя старые попытки.
Фиксированный список хранится при создании занятия, попытка ссылается на версию.
Внешние ресурсы пока не используются; абсолютные пути к пользовательским файлам
не включаются в учебные данные.

Идентификатор запроса передаёт вызывающая сторона. Повтор с тем же содержанием
не создаёт редакцию, повтор с другим содержанием вызывает ошибку. Завершение
попытки и обновление моделей выполняются в одной транзакции.
Исключение хранения означает, что операция не подтверждена: UI должен показать ошибку сохранения.

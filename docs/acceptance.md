# Проверки

Окружение: Windows, GCC 5.1, C++11, SFML 2.5.1, Win32.
Debug и Release: 19 групп сервисных тестов и отдельные сценарии интерфейса.

| Область | Что проверяется |
|---|---|
| Математика | Дроби, разбор выражений, корни, преобразования, границы ввода; 589 независимых примеров по арифметике и формулам Виета |
| Генераторы | 250 заданий, воспроизводимость, согласованность частей |
| Хранение | Миграция 13→14 с сохранением истории; отказ записи наблюдения и модели, откат, повтор запроса и перезапуск |
| Занятия | Исправления, подсказки, отложенная проверка, неизменность фиксированного набора |
| Адаптация | BKT/Elo, исключение помощи, повторный спуск по графу и возврат |
| Восстановление | Шаблоны, черновики, пауза, ограничения времени |
| Пересмотр | История вердиктов, сохранение автопроверки, пересчёт моделей, CSV |
| Доступ | Пароль, запрет редактирования без входа, выход, архив профиля |
| JSON и потоки | Собственный разбор, Unicode, пути, обмен, отмена и устаревшие результаты |
| Демонстрация | Связность навыков, 49 заданий, рекурсивный разбор, очередь проверки, пауза |
| Интерфейс | Ввод, фокус, формулы, графики, составное задание, настройка и сохранение шаблона |
| ОГЭ | 53 навыка, 212 упражнений, граф без циклов, версии карточек, повторный импорт, исключение решённых, повреждённый рисунок и восстановление |
| Лекции | Публикация и черновики, доступ ученика, PDF, проверка путей и конфликт правок, помощь без двойного учёта |
| Тренировка ОГЭ | Ошибка → лекция → возврат с черновиком; разбор по необходимым навыкам → исходная задача → следующая задача фиксированного набора |

Запуск: `run.bat tests`. Снимки интерфейса сохраняются в `bin/captures/`.
`smart_exam.exe --capture` снимает полные экраны с навигацией.

Сетевая проверка 12.11.2026: `smart_exam.exe --check-oge-all` получил по одной
карточке каждого из 53 подтипов, охватывающих все 19 номеров. У всех карточек
ключ проходит обычную проверку краткого ответа. Декодированы все 68 различных
изображений из этой выборки (74 ссылки). Это проверка интеграции с ключами источника,
а не независимое доказательство правильности каждого ответа всего банка.

Проверочные базы создаются отдельно. Загруженные условия не входят в репозиторий
или дистрибутив. Пределы и измерения описаны в [limits.md](limits.md).
Прямое подключение к банку ФИПИ не работает; используется согласованный
альтернативный источник. Запуск на другом физическом компьютере не проверялся.

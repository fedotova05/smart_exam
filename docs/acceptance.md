# Проверка первого этапа

Окружение: Windows, TDM GCC 5.1.0, SFML 2.5.1, SQLite 3.46.1, C++11, Win32.

| Задача | Проверка |
|---|---|
| T01 | Debug/Release, запуск и закрытие окна |
| T02 | Неизменность версий, откат транзакции, повтор запроса, повторное открытие БД |
| T03 | Дроби, приоритеты, ошибки и пределы ввода |
| T04 | 81 пара целых корней, радикалы, потеря корня, действия над уравнением |
| T05 | 250 заданий пяти семейств, воспроизводимость, общие параметры частей |
| T06 | Исправления, три режима показа проверки, помощь, однократная сдача |
| T07 | Формулы BKT/Elo, исключение помощи, изменение подбора, неизменность фиксированного набора |

Сценарий `--demo`: неверный ответ → исправление → 1 балл → BKT 0.127273,
Elo 984 → более простое задание. Ошибка остаётся в истории модели.

T07 проверена и принята локально: [протокол](reviews/T07.md).

# Сборка

Основной путь — Code::Blocks, проекты `project/smart_exam.cbp` и `project/tests.cbp`.
Выбрать GCC, в глобальной переменной `sfml` указать каталог совместимого комплекта SFML.
Компилятор и библиотеки должны совпадать по архитектуре и ABI. Для запуска динамические
DLL из каталога SFML/bin должны быть доступны в PATH. Рабочий каталог проектов — корень репозитория.
Оба проекта используют C++11. Сначала собрать и запустить tests, затем smart_exam.

Дополнительный путь проверки из корня: `python tools/build.py --mode Debug --smoke`,
затем `python tools/build.py --mode Release`. Путь компилятора задаётся `--compiler`,
путь библиотеки — `--sfml`. Python нужен только для вспомогательной сборки, не для приложения.
После добавления исходников обновить проекты командой `python tools/update_projects.py`.

Локально обнаружены TDM GCC 5.1.0 (mingw32) и SFML 2.5.1 (i386).
Это 32-битный комплект; успешная сборка им не подтверждает целевую Windows x64.
Проверка согласованного x64-комплекта и сборка на компьютере участника 2 остаются отдельными пунктами приёмки.

Пустое окно в T01 — точка подключения интерфейса участника 2. Параметр `--smoke`
открывает окно и закрывает его через секунду для проверки запуска.

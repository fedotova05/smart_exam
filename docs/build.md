# Сборка и перенос

Нужны Windows, GCC с C++11 и SFML 2.5.1 той же разрядности.
Проверяемый комплект: TDM GCC 5.1, SFML 2.5.1, Win32.
Python нужен для вспомогательной сборки и упаковки, но не для запуска приложения.

```text
python tools/build.py --mode Debug
python tools/build.py --mode Release
python tools/package_release.py
```

По умолчанию компилятор: `C:/Program Files/CodeBlocks/MinGW/bin/g++.exe`,
SFML: `C:/SFML-2.5.1`. Другие пути задаются через `--compiler` и `--sfml`.
Сборка запускает предметные тесты, сценарии интерфейса и консольную демонстрацию.

Основной проект Code::Blocks — `smart_exam.cbp`. Рабочая папка — корень проекта,
рядом с `db/` и `data/`. После изменения списка исходников выполните
`python tools/update_projects.py`. SQLite компилируется как C, остальной код — C++11.

SFML подключена статически. Системные библиотеки: `opengl32`, `freetype`,
`winmm`, `gdi32`, `comdlg32`, `shell32`. Сетевые функции загружаются из системной
`winhttp.dll`; проверка сертификатов включена. SVG преобразует resvg 0.50.0; бинарный файл, версия, контрольная сумма
и лицензия находятся в `third_party/resvg`. Для него нужна Windows x64.
Основное приложение собрано как Win32.

Шрифты Segoe UI/Arial и Georgia берутся из Windows/Fonts.
Минимальный размер окна — 1024×720. F11 переключает полноэкранный режим.

`run.bat tests` запускает тесты выбранной сборки, `run.bat demo` — демонстрацию.
`smart_exam.exe --check-oge` проверяет сетевую загрузку по одному заданию
каждого номера. `--check-oge-all` проверяет все 53 подтипа. Каждый запуск создаёт
отдельную базу; путь записывается в `bin/oge-source-check-path.txt`.

Локальный выпуск создаётся в `packaging/output/`. Архив содержит программу,
библиотеки её компилятора, миграции, учебные материалы и инструкции.
Личные базы, скачанные задачи и вложения преподавателей в выпуск не входят.
Запускать нужно через `start.bat`, чтобы рабочая папка совпадала с папкой программы.
Упаковщик проверяет запуск из новой папки с PATH, содержащим только системный
каталог Windows. Это проверка переноса на том же компьютере, не испытание на другой машине.

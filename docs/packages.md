# Учебные пакеты

Схема 1, кодировка UTF-8 без BOM. Пример: `data/samples/algebra.json`.
В пакете только задания и ресурсы: без профилей, ответов и истории учеников.

Обязательные поля: `schema`, `id`, `skills`, `tasks`.
У задания: `id`, `title`, `difficulty`, `parts`.
У части: `id`, `kind`, `prompt`, `expression`, `score`, `skills`.
Типы: 0 — выражение, 1 — уравнение, 2 — прямая, 3 — парабола.
Необязательные поля задания: `description`, `function`, `resources`.
У части: `snap` (по умолчанию 0.5), `tolerance` (0.0001).

Пределы: JSON 2 МБ, вложенность 32, 20000 значений, строка 64 КБ;
100 заданий и 100 навыков на пакет, 100 частей на задание.
Ресурсы PNG/JPEG: до 8 файлов на задание, до 5 МБ каждый.
Пути относительные, из латинских букв, цифр, `_`, `-`, `.`, `/`.
Абсолютные пути, `..`, системные имена и ссылки не принимаются.

Порядок импорта: выбрать файл → прочитать → сопоставить каждый навык
с существующим → импортировать → просмотреть отчёт. Ошибка одной задачи не мешает остальным.
Внутренний id имеет вид `пакет.задание`. Повторный импорт такого id пропускается.
Файлы копируются в `data/imports/`. Импортированные задания всегда остаются черновиками;
перед публикацией их нужно проверить в редакторе.

Экспорт: выбрать задания и сохранить JSON. Ресурсы записываются рядом с ним;
передавать нужно всю полученную папку. Если сопоставить два навыка одной части
с одним местным навыком, проверка сообщит о повторе: исправьте сопоставление.

Разбор реализован в `Json.cpp`: строки и экранирование, числа, массивы, объекты,
логические значения и null. Повторные ключи, лишние запятые, неверный UTF-8,
неполные Unicode-пары и выход за пределы отвергаются.

# Демонстрация

Основной демонстрационный курс содержит 49 заданий и 14 связанных навыков.
При открытии приложения устанавливается также курс ОГЭ: 53 навыка, 212 упражнений
и 53 лекции. Все эти примеры составлены для проекта.

| Профиль | Что показать |
|---|---|
| Мой профиль · начать с нуля | Самостоятельно выбрать темы и пройти тренировку |
| Демо · поиск причины ошибки | Ошибка в квадратном уравнении, проверка составляющих навыков, повторная ошибка в простом упражнении, спуск к целым числам и возврат |
| Демо · проверка знаний | Три формата: выбор вариантов, многочлен, число с округлением; результат после всего занятия |
| Демо · ответ для учителя | Текстовый ответ, который автоматическая проверка не разобрала; очередь ручной проверки |
| Демо · занятие на паузе | Сохранённый ответ, графическое задание, продолжение таймера |

Кнопка «Посмотреть демонстрацию» открывает подробный маршрут поиска ошибки.
История получена обычными вызовами сервисов; ошибки специально заданы сценарием.

Направление связи в графе: необходимый навык → следующий навык.
Например: целые числа → знаки → дискриминант → корни квадратного уравнения.
Для формулы корней также нужны дроби и квадратный корень.

В кабинете учителя доступны шаблоны фиксированного варианта и адаптивного подбора.
При первом входе учителя задайте собственный пароль. Общего демонстрационного пароля нет.

## ОГЭ и лекции

1. Войти как учитель и открыть «Задания ОГЭ».
2. Импортировать `data/samples/oge-2026.json`: появятся 19 карточек, по одной на номер.
   Повторный импорт сохраняет те же версии.
3. Выбрать ученика и назначить подборку. Войти за этого ученика и открыть назначение.
4. Отправить неверный ответ. Выбрать лекцию, прочитать её и вернуться к заданию.
   Введённый ответ сохранится; чтение будет отмечено как помощь.
5. Выбрать разбор на простых заданиях, пройти его и вернуться к исходной задаче.
   Затем продолжить фиксированную подборку; её состав не изменится.
6. Для реального источника выбрать подтип, включить загрузку из интернета и запросить
   одну карточку. После загрузки её можно решать без сети.

Лекции можно дополнить: «Лекции» → «Создать лекцию» → текст и навыки →
«Опубликовать». Для проверки вложения прикрепите собственный PDF или Word.

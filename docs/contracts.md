# Общие контракты

Участник 1 — Анастасия. Стандарт языка — C++11.

`src/core/Types.h` содержит данные без SFML и SQLite. Идентификаторы — строки.
TaskVersion хранит конкретное содержание задания; TaskPart — одну оцениваемую часть.
AnswerPayload содержит текст и графический ответ в математических координатах.
GraphAnswer передаёт точки и коэффициенты функции, а не пиксели окна.
StudentSnapshot хранит известность оценки отдельно от начального значения модели.

CheckResult различает Correct, Incorrect, Unsupported, InvalidInput и Incomplete.
Только Incorrect является установленной математической ошибкой. Неподдерживаемая
проверка и незавершённое решение не должны отображаться как неверный ответ.

Checker::checkAnswer проверяет ответ на часть. Checker::checkStep принимает исходное
и новое уравнение, название действия и операнд. Пустое действие означает свободный режим.
Графический проверяющий модуль участника 2 подключается через GraphChecker.
Реализация GeometryChecker проверяет прямые и параболы; неизвестный формат возвращает Unsupported.

Generator::generateTask создаёт задание; SessionService::submitResponse сохраняет ответ;
finishAttempt завершает попытку; TaskSelector::selectNext подбирает следующее задание.
Импорт JSON реализован через PackageService. Ручной пересмотр выполняется через ReviewService и SchoolService с проверкой входа учителя.
SQL вызывается только из слоя хранения.

Расширение KChernmo для занятий по темам:
- `SessionSettings::training` включает тренировку с немедленной проверкой; `targetSkills` ограничивает обычный подбор.
- `SchoolService::startTopics` запускает тренировку или неизменный набор проверки.
- `canSupport` и `startSupport` предлагают разбор только после неверного ответа в тренировке.
- `TrainingService` подбирает упражнения по графу и банку. Экраны не рассчитывают маршрут.
- `TaskPart::displayExpression` задаёт формулу условия, когда проверяемое значение отличается от неё.
  Пустое поле сохраняет прежнее отображение `expression`. JSON читает это поле необязательно.

Текущая версия базы — 11. Возврат к исходному заданию не обновляет модель повторно.
Ограничения и порядок работы: [training.md](training.md).

# Демонстрационный набор

На экране входа нажмите «Посмотреть демонстрацию». Откроется профиль
«Демонстрация: разбор ошибки» с историей из девяти попыток:

1. Неверные корни уравнения `2*x^2-3*x-2=0`.
2. Верно определены коэффициенты: `2`, `-3`, `-2`.
3. Ошибка в дискриминанте.
4. Ошибка в произведении `4*2*(-2)`.
5. Верно: `(-3)*5 = -15`.
6. Верно: `(-4)*(-6) = 24`.
7. Верно вычислен дискриминант другого уравнения: `16`.
8. Возврат к исходной задаче: `2;-1/2`.
9. Новый пример `3*x^2+2*x-1=0`: `-1;1/3`.

Упражнения выбирает обычный `TrainingService`. Только ответы учебного профиля заранее заданы.
Кнопка «Пройти похожий маршрут» создаёт новый профиль. Чтобы увидеть разбор,
отправьте неверные корни, затем выберите простые задания. Дальнейший путь зависит от ответов.
Кнопка «Прогресс примера» показывает фактические оценки и число наблюдений.

Старые пять заданий и профиль «Демонстрация» с двумя ответами сохранены:

| Задание | Ответ для проверки |
|---|---|
| Сложение дробей: 1/2 + 1/3 | `5/6` |
| Линейное уравнение: 2x + 3 = 11 | `4` |
| Два корня: x² − 5x + 6 = 0 | `2;3` |
| Прямая: y = 2x + 1 | Точки (0; 1) и (1; 3) |
| Корни и парабола: y = x² − 4 | `-2;2`, затем a = 1, b = 0, c = −4 |

В истории уже есть пример верного решения дроби и исправления ошибки в уравнении.
Карта знаний показывает наблюдения по этим двум навыкам. Другие навыки остаются без наблюдений.
Повторный запуск не создаёт дубликаты и не сбрасывает результаты.

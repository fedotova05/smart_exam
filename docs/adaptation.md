# Адаптация

Один навык даёт одно наблюдение за попытку. Помощь и непроверенный итог исключают
наблюдение из обучения. Ошибка с последующим исправлением остаётся неуспехом для
модели, но балл за окончательный ответ начисляется по обычному правилу.

BKT: сначала вероятность знания пересчитывается по ответу, затем учитывается обучение.
Elo: рейтинг меняется на K × (результат − ожидаемая вероятность успеха).
Параметры bkt-elo-1 хранятся в базе: initial=0.2, learn=0.1, slip=0.1, guess=0.2, K=32.
Это начальные настройки, не результат исследования эффективности.

Подбор учитывает неизвестные и слабые навыки, сложность, предпосылки и повторы.
Предпосылки снижают приоритет, но не запрещают задание. Цикл в графе отклоняется.
Черновики и архивные задания исключены. Текущее задание сразу не повторяется;
если альтернатив нет, возвращается понятный отказ. Равный приоритет разрешается по id.

Снимок до ответа, наблюдения и обновлённая модель сохраняются вместе с результатом
попытки. Повтор finishAttempt не обучает модель второй раз.

# Занятия

SessionService: start → next → submitResponse → finishAttempt → next.

- Fixed: список сохраняется при старте и не меняется вместе с банком.
- Dynamic: TaskSelector вызывается только после завершения текущей попытки.
- Один ученик имеет одну незавершённую попытку. Снимок навыков сохраняется до ответа.
- Шаг проверяется относительно последнего верного шага. Все исправления остаются в истории.
- За часть начисляется максимум или ноль. Непроверенные части дают предварительный итог.
- Повтор запроса с тем же id безопасен; другое содержание с тем же id отклоняется.
- Проверка видна после шага, задания или набора согласно FeedbackPolicy.
- GraphChecker подключает участник 2; до подключения графический итог предварительный.

SQL и исключения сохранения обрабатываются в Store. UI использует SessionService::history
и result, чтобы не раскрывать скрытую проверку. Расширенные таймеры и ручной пересмотр — вне T06.

# Лекции

Откройте «Лекции» в меню. Поиск работает по названию и тексту; список слева
фильтрует материалы по навыку. Ученик видит опубликованные лекции.

Учитель нажимает «Создать лекцию», вводит название и текст, отмечает навыки.
Можно прикрепить PDF, DOC или DOCX до 20 МБ. Текст читается в приложении;
вложение открывается программой Windows для этого формата. DOC/DOCX внутри
приложения не преобразуются. Для публикации нужен хотя бы один навык.

Черновик доступен только учителю. Опубликованную лекцию можно изменить,
снять с публикации или убрать в архив. При одновременном редактировании
сохранение устаревшей версии отклоняется.

В тренировке кнопка «Лекции» показывает материалы по текущему навыку,
затем по его непосредственным предпосылкам. После неверного ответа можно
выбрать лекцию, разбор на простых задачах или самостоятельное исправление.
Открытие лекции учитывается как помощь. Повторное открытие того же материала
не создаёт повторной записи помощи. Попытка и черновик ответа сохраняются.

Лекции хранятся в SQLite, копии вложений — в `data/lectures/`.
Для резервной копии закрывайте приложение и копируйте всю папку `data`.

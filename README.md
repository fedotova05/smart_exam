# SmartExam

Учебный проект на C++11, SFML и SQLite.
Участник 1 — Анастасия (`fedotova05`). Первый этап: T01–T07.

Инструкции сборки: [docs/build.md](docs/build.md).
Общие данные и границы модулей: [docs/contracts.md](docs/contracts.md).

Реализованы точные дроби, разбор выражений, уравнения до второй степени,
проверка шагов, генераторы, история в SQLite, занятия, BKT, Elo и подбор заданий.

Проверки: Debug/Release Win32, 7 групп тестов, 250 сгенерированных заданий.
Демонстрация: `run.bat demo`. Проверки: `run.bat tests`.

T01–T06 находятся в main. T07 — в `feature/07-adaptation`, ожидает приёмки.
Интерфейс и графическая проверка относятся к участнику 2; сейчас окно пустое.

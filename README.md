# SmartExam

Приложение для занятий математикой на C++11, SFML и SQLite. Учитель создаёт задания,
назначает занятия и публикует лекции. Ученик решает задачи, разбирает ошибки
и видит прогресс по навыкам.

В разделе «Задания ОГЭ» доступны номера 1–19 по математике за 2026 год.
Карточки загружаются из «Решу ОГЭ» и сохраняются на компьютере. Учитель может
импортировать собственную подборку. Навыки назначаются по подтипу задания.
В тренировке можно прочитать связанную лекцию или перейти к простым упражнениям.

Сборка: `python tools/build.py --mode Release`. Запуск: `run.bat`.
В Code::Blocks откройте `smart_exam.cbp`, выберите Debug или Release и нажмите F9.
При первом входе учителя задайте локальный пароль.

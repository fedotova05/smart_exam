# SmartExam

Учебный проект на C++11, SFML и SQLite.
Участник 1 — Анастасия (`fedotova05`), T01–T07.
Участник 2 — `KChernmo`, T08–T15.

Инструкции сборки: [docs/build.md](docs/build.md).
Общие данные и границы модулей: [docs/contracts.md](docs/contracts.md).

Занятия с проверкой выражений, уравнений и графиков. Есть редактор заданий,
карта знаний, история в SQLite и обмен учебными пакетами JSON.
JSON разбирается собственным кодом. Подбор заданий использует BKT и Elo.

Открыть **smart_exam.cbp** в Code::Blocks, выбрать Debug и нажать Build and Run.
После сборки: `run.bat`. При входе выберите «Я ученик» или «Я учитель».
Ученик создаёт личный профиль или выбирает существующий, решает задания и смотрит прогресс.
Учитель работает с банком и пакетами, готовит занятия и просматривает результаты учеников.
Кабинет учителя защищён локальным паролем, который задаётся при первом входе.
Ученик выбирает темы для тренировки или проверки знаний. В новой базе 49 учебных заданий
и 14 связанных навыков. Демонстрация показывает повторный спуск к более простому навыку
после ошибки и возврат к исходной задаче.

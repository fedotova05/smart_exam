# SmartExam

Учебный проект на C++11, SFML и SQLite.
Участник 1 — Анастасия (`fedotova05`), T01–T07.
Участник 2 — `KChernmo`, T08–T15.

Инструкции сборки: [docs/build.md](docs/build.md).
Общие данные и границы модулей: [docs/contracts.md](docs/contracts.md).

Занятия с проверкой выражений, уравнений и графиков. Есть редактор заданий,
карта знаний, история в SQLite и обмен учебными пакетами JSON.
JSON разбирается собственным кодом. Подбор заданий использует BKT и Elo.

Открыть **smart_exam.cbp** в Code::Blocks, выбрать Debug и нажать Build and Run.
После сборки: `run.bat`. Сразу доступны профиль «Демонстрация» и пять заданий.
На главной можно запустить короткое занятие из трёх заданий.
Свой профиль и режим занятия выбираются через «Профили и настройки».

Проверки: `run.bat tests`; элементы интерфейса: `run.bat widgets`.
Инструкция к интерфейсу: [docs/interface.md](docs/interface.md).
Формат пакета: [docs/packages.md](docs/packages.md).
Ограничения ФИПИ: [docs/fipi.md](docs/fipi.md).

T07 принята. T08–T15 проверены локально и подготовлены к ревью.
Проверка x64 и сборка на другом компьютере остаются отдельными пунктами.

# SmartExam

Учебный проект на C++11, SFML 2.5.1 и SQLite. Программа для решения задач
по математике. Есть роли ученика и учителя, тренировки, история ответов и лекции.

Задачи первой части ОГЭ по математике загружаются из «Решу ОГЭ».
После загрузки их можно решать без интернета. Банк ФИПИ напрямую не подключён.

Для сборки в Code::Blocks нужно открыть `smart_exam.cbp`.
По умолчанию используется GCC из `C:/Program Files/CodeBlocks/MinGW`
и SFML из `C:/SFML-2.5.1`. Если пути отличаются, их нужно поменять в настройках проекта.

Также можно собрать командой `python tools/build.py --mode Release`.
Запуск из проекта — `run.bat`, из готового архива — `start.bat`.
Для тестов — `run.bat tests`.

При первом входе учителя нужно задать пароль. Данные сохраняются в `data/smart_exam.db`.
Для открытия вложенных PDF и Word нужна установленная программа.
Преобразование рисунков SVG использует resvg из `third_party/resvg` и требует Windows x64.

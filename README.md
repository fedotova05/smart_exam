# SmartExam

Учебное приложение на C++11, SFML и SQLite. Ученик выбирает темы, решает задания
и смотрит прогресс. Учитель готовит занятия, редактирует банк и проверяет ответы.

Открыть `smart_exam.cbp` в Code::Blocks, выбрать Debug и нажать F9.
После сборки: `run.bat` — приложение, `run.bat tests` — тесты.
При первом входе учителя нужно задать локальный пароль.

Новая база содержит 49 заданий, 14 связанных навыков и 5 профилей для демонстрации.

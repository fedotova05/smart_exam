# SmartExam

Учебное приложение на C++11 и SFML с хранением в SQLite.
Участник 1 — Анастасия (`fedotova05`): математика, хранение, занятия и адаптация.

Инструкции сборки: [docs/build.md](docs/build.md).
Общие данные и границы модулей: [docs/contracts.md](docs/contracts.md).

Работа выполняется по задачам T01–T07, в отдельных ветках `chore/01-project-base` и далее.
Промежуточные задачи сливаются после локальных проверок; последняя ожидает приёмки.
